# WGS Reference Index

## Purpose

This folder preserves the planning lineage behind the Aptlantis governance system.
These files are not active standards unless a standard suite explicitly cites them as authoritative.

They matter because they carry tone, intent, and design memory.
The standards should remain practical, recoverable, and agent-friendly, not ceremonial.

## Conversation Lineage

The long-form planning conversations live in `references/conversations/`.
Use them when a standard feels mechanically correct but philosophically thin.

Primary lineage file:

- `references/conversations/ChatGPT-Standards Framework Development.md`

## Use Rule

Reference files may inform tone and planning, but active implementation should follow the standard suites:

- WGS for workspace structure.
- SFDS for standard authoring.
- PPS for project proposals.
- DRS, CTS, SIS, WDS, DDS, and LDS for project classes.
