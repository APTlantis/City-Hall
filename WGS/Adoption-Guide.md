# WGS Adoption Guide

Adopt WGS for any root, project, service, or standard that should be discoverable by humans and agents.

## Steps

1. Inventory the current location.
2. Identify the governing standard.
3. Add the appropriate manifest type.
4. Add `PROJECT-READMAP.toml` for project and project-group roots.
5. Link human-readable docs from the manifest.
6. Record known gaps instead of silently correcting them.

## SFDS Relationship

Use SFDS to maintain WGS as a standard suite.
Use WGS to govern workspace placement, manifest naming, root registration, and agent startup.
