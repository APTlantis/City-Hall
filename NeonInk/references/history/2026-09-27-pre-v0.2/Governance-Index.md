## Governance Rule

Existing docs remain authoritative unless a later SFDS-compliant version explicitly supersedes them.

## Scope

NeonInk governs semantic color systems, visual intent, theme behavior, UI language, component styling patterns, and generated design assets.

## Does Not Govern

NeonInk does not govern application release packaging, workspace directory policy, archive hashing, CLI behavior, or dataset provenance.
