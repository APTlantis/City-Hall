# NeonInk Changelog

## 0.1.6 - 2026-06-11

- Updated active compatibility notes from SESM v0.2.x to SESM v0.3.x after the SESM public-review profile cleanup.

## 0.1.5 - 2026-06-11

- Updated mirrored SESM examples to use the v0.3.0 public-review metadata profile.

## 0.1.4 - 2026-06-11

- Updated mirrored SESM documentation and SVG panel examples to use `llm.interpretation_hints`.
- Aligned NeonInk's SESM-facing examples with the safer non-authoritative agent-context vocabulary.

## 0.1.3 - 2026-06-11

- Expanded NeonInk scope to include desktop application surfaces and data-dense tool UIs.
- Added app guidance for panels, stateful tools, icon usage, semantic glow, and accessibility on dark UI.
- Updated adoption and validation guidance for app development under SFDS.
- Recorded FileCabinet as a practical adopter pattern for health, hash, icon, and dense-list UI behavior.

## 0.1.2 - 2026-06-10

- Added SFDS two-layer suite metadata to the NeonInk standard manifest.
- Added a NeonInk suite map example.
- Clarified README, adoption, and validation language for suite conformance versus design-system adoption readiness.

## 0.1.1 - 2026-06-10

- Added WGS/SFDS governance wrapper.
- Preserved existing NeonInk docs and assets as authoritative source material.
