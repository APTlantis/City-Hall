# NeonInk suite map

The suite manifest describes the standard; the TOML token source describes the palette and semantic contract. The compiler validates those tokens and emits consumable CSS/JSON. Layout, data and profile documents define adoption behavior. The adoption template records project-specific scope and evidence.

`examples/reference-data.json` feeds three deterministic SVG reference boards. PNG previews are visually reviewed output. `examples/presentation.html` provides a responsive reading specimen with direct values and a table. All example measurements are synthetic.

Legacy documents and images are preserved evidence, not active consumer contracts for new adoption. Current entrypoint: `../README.md`.
