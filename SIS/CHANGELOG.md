# SIS Changelog

## 0.1.0 - 2026-06-12

- Created the initial Service and Infrastructure Standard suite.
- Defined SIS as the delivery standard for WGS service and infrastructure project classes.
- Added lifecycle, health check, port, storage, log, resource, dependency, recovery, and agent-orientation requirements.
- Added service manifest, runbook, health check, and resource constraint templates.
- Added local API and workspace cache service examples.
