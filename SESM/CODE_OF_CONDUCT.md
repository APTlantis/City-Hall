# Code of Conduct

## Standard

Participants should keep SESM review technical, specific, and respectful.

Good review:

- names concrete risks;
- cites files, examples, or validator behavior;
- distinguishes safety concerns from style preferences;
- proposes wording or fixture improvements when possible;
- assumes good faith while still treating security and privacy issues seriously.

## Unacceptable Conduct

Unacceptable conduct includes:

- harassment or personal attacks;
- publishing private information;
- pressuring maintainers to include unsafe behavior;
- intentionally submitting malicious SVGs outside a clearly marked security report;
- using SESM examples to smuggle credentials, tracking identifiers, or agent instructions.

## Reporting

Report conduct issues to the current maintainer listed in `SESM.manifest.toml`.

Security issues should follow `SECURITY.md`.
