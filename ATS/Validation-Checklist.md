# ATS Validation Checklist

This checklist validates agent-task readiness under ATS. SFDS suite conformance for ATS is tracked by `ATS.manifest.toml` and the ATS suite map.

- [ ] Task goal is recorded.
- [ ] Starting context is recorded.
- [ ] Governing standard is identified.
- [ ] Actions taken are summarized.
- [ ] Validation is recorded.
- [ ] Remaining work is documented.
- [ ] Handoff note exists when applicable.
- [ ] Task lifecycle state is assigned.
- [ ] Files inspected or changed are identified.
- [ ] Decisions and important assumptions are recorded.
- [ ] Blockers include the next safe action.
- [ ] Completion is not claimed without validation or an explicit validation gap.
