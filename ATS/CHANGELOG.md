# ATS Changelog

## 0.2.1 - 2026-06-11

- Added filled examples for a completed agent task record and a blocked handoff note.
- Clarified practical ATS usage for replayability, validation evidence, and safe continuation.
- Added a lightweight agent task record schema.

- Promoted ATS to candidate maturity.
- Added task lifecycle states, starting context requirements, action records, validation records, handoff requirements, replayability rules, and drift controls.
- Clarified the relationship between WGS orientation, PPS intent, AAS evidence, and ATS task history.

- Added SFDS two-layer suite metadata to the ATS standard manifest.
- Added an ATS suite map example.
- Clarified README, adoption, and validation language for suite conformance versus agent-task readiness.
