# ATS Adoption Guide

Use ATS when agent work must be auditable, resumable, or handed off cleanly.

## Steps

1. Start a task record.
2. Record starting context and governing standards.
3. Record actions and validation.
4. Leave a handoff note if work remains.
5. Mark task lifecycle state clearly.
6. Record blockers, assumptions, and next safe action when the task cannot complete.
7. Do not mark a task complete without validation or an explicit validation gap.

## SFDS Relationship

Use SFDS to maintain ATS as a standard suite.
Use ATS to govern auditable agent work, task records, lifecycle state, and handoff quality.
