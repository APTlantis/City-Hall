# AAS Validation Checklist

This checklist validates analysis/evaluation readiness under AAS. SFDS suite conformance for AAS is tracked by `AAS.manifest.toml` and the AAS suite map.

- [ ] Analysis manifest exists.
- [ ] Input references are recorded.
- [ ] Tool versions are recorded.
- [ ] Run record exists.
- [ ] Metrics are preserved.
- [ ] Interpretation notes are included.
- [ ] Limitations are documented.
- [ ] Metric definitions include unit, calculation, denominator, and exclusions where applicable.
- [ ] Environment and command/procedure are recorded.
- [ ] Comparison baseline is named when comparisons are made.
- [ ] Interpretation distinguishes facts, inferences, assumptions, and caveats.
- [ ] Dataset limitations from DDS are carried into the analysis record.
