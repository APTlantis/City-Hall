# AAS Adoption Guide

Use AAS when an evaluation or analysis result should be credible, reproducible, and recoverable.

## Steps

1. Create an analysis manifest.
2. Record inputs, tools, versions, and environment.
3. Record evaluation commands and outputs.
4. Preserve metrics and interpretation notes.
5. Record limitations and follow-up questions.
6. Define every reported metric.
7. Name comparison baselines and interpretation boundaries when results are used for decisions.

## SFDS Relationship

Use SFDS to maintain AAS as a standard suite.
Use AAS to govern reproducible analysis records, evaluation runs, evidence, metrics, and interpretation limits.
