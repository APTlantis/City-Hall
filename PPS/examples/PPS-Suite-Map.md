# PPS Suite Map

## Suite Layer

PPS is indexed by `PPS.manifest.toml`, `README.md`, and `Project Proposal Standard.md`.

## Adopter Layer

Project adopters use `ProjectProposal.manifest.schema.toml`, `templates/Project-Proposal.md`, and `templates/PROJECT.manifest.toml` as the generic v2.4 template while real projects use entity-named manifests.

## Validation Layer

Validate proposal readiness with `Validation-Checklist.md` before broad implementation begins.
