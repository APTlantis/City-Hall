# Presentation workflow

Identify the audience, question, dataset/source, units, period, and destination. Infer routine choices from the user's project; request missing data when it controls the conclusion. A designed fixture is acceptable only when visibly labeled synthetic.

Choose analytical report, dataset profile, or explanatory plate from the suite layouts. Build the chart and the accessible values together. Keep category colors stable across filtering, sorting and exporting. Publish ordered bin boundaries and missing-data behavior. Distinguish percentage change from percentage points and coverage from quality.

Review at intended size: headline/plot balance, readable axes/source, numeric alignment, legends, small-screen stacking, zoom, keyboard focus and exported clipping. Test the real export, not just the source canvas. Interactive charts need non-hover value access; static figures need visible interpretation and accessible companion values.

If embedded in an operational app, scope the presentation styles and keep the host's navigation/control anatomy. In a report, space belongs primarily to the argument and evidence rather than decorative cards.
