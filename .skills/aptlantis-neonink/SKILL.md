NeonInk is the expressive data-presentation system. Blue Slate is the house theme for dense operational applications. Keep the host shell when embedding a NeonInk report; the standard does not authorize retheming unrelated applications.

## Shared rules

Use the question and data to choose the chart. Never invent real measurements, certainty, quality checks, or provenance. Label synthetic fixtures in every exported view. Expose units, period, denominator, source, and material limitations. Distinguish missing from zero and estimates from observations.

Preserve exact historical palette values during representation migration. Use semantic roles for UI and named scales for data; category identity is not operational status. Green status requires evidence. Red is risk, not generic emphasis. Signed differences use the neutral-centered diverging scale unless desirability is established. Avoid color-only distinctions, decorative glow, and tooltip-only facts.

Use the reference catalog for composition, not token sampling or claims of runtime proof. Generate precise charts and reference boards from data with normal graphics/plotting tools. Illustrative imagery cannot serve as a data visualization or exact token reference.

Complete authorized work and its relevant checks. Report version, source, actual tests, outputs, deviations, and remaining runtime/export gaps. Suite validation does not establish a live deployment or stable maturity. Do not publish, install globally, or modify unrelated adopters solely because this skill was invoked.
