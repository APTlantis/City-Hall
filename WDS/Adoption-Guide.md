# WDS Adoption Guide

Use WDS for public websites, internal web dashboards, static sites, and web applications.

## Steps

1. Create a site manifest.
2. Record deployment target and build process.
3. Complete accessibility and SEO checks.
4. Document static asset organization.
5. Record monitoring and uptime expectations.
6. List key routes and check them after deployment.
7. Document rollback or restore expectations before production publication.

## SFDS Relationship

Use SFDS to maintain WDS as a standard suite.
Use WDS to govern website manifests, deployment records, accessibility, SEO metadata, and operational expectations.
