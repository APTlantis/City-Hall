# Blank Governance and Project Forms

This directory is the canonical source for reusable onboarding forms on the Dev Drive. Standards remain authoritative in their suites; these are copied, commonly used starting points for new work.

## Canonical Sources

| Form | Source of truth | Use |
| --- | --- | --- |
| `DirectoryName.manifest.toml` | `D:\.city_hall\WGS\templates\DirectoryName.manifest.toml` | Governed portfolio or directory manifest. |
| `ProjectName.manifest.toml` | `D:\.city_hall\WGS\templates\ProjectName.manifest.toml` | Project or project-group manifest. |
| `Project-README-TEMPLATE.md` | `D:\.city_hall\WGS\templates\Project-README.md` | Internal project context and recovery notes. |
| `README-TEMPLATE.md` | Maintained in this directory | Public-facing project README format. |
| `StandardName.manifest.toml` | `D:\.city_hall\SFDS\templates\StandardName.manifest.toml` | Standards-suite manifest. |
| `DatasetName.manifest.toml` | `D:\.city_hall\DDS` | Dataset manifest starter; verify against the current DDS standard before use. |

Do not edit a copied form as though it were the canonical standard. When a suite template changes, refresh its copy here and keep this source map current.
