# Blue Slate SiYuan Profile

The generated `generated/BlueSlate.SiYuan.css` is the supported adapter for SiYuan. It maps only documented `--b3-*` compatibility variables to framework-neutral Blue Slate roles; it does not make SiYuan names canonical or attempt to replace an adopter's layout and behavior rules.

Regenerate it with `tools/Compile-BlueSlate.ps1`. Project-specific SiYuan variables belong in the adopter theme and should be recorded as local-profile decisions.
