## Important findings and boundaries

- The original compiler's `-Check` did not compare existing outputs and created its output directory. The revised check neither writes nor creates directories and fails on missing/stale output. Tests exercise these failures, custom source/output, invalid TOML, policy, references and cycles.
- Original `Test-BlueSlate.ps1` did not propagate Node conversion failures; it now does and honors the selected root for source/output checking.
- Exact hex/OKLCH verification covers 27 palette entries. Existing inline OKLCH expressions for link-hover, translucent borders and elevation are preserved and remain outside that check. They need rendered/composited review when used.
- The neutral CSS's explicit hex properties are available to adapters, but semantic CSS uses OKLCH; no automatic old-renderer fallback is claimed.
- The supplied swatch board uses compact labels and is palette evidence, not an accessible application UI. Rendering the board again does not establish adopter contrast.
- The palette extractor smoke covers its default 32-color workflow with the supplied HolyC JPG. Broader image diversity, alternate culture formatting, other color counts and repeatability are not certified. Its generated theme format is not the Blue Slate schema.
