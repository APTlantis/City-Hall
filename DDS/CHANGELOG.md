# DDS Changelog

## 0.2.1 - 2026-06-11

- Added license and split record templates.
- Added filled license and split record examples.
- Added a lightweight dataset manifest schema.

## 0.2.0 - 2026-06-11

- Promoted DDS to candidate maturity.
- Added dataset classes, derived-data lineage rules, split rules, sensitive-data constraints, integrity guidance, and release blockers.
- Clarified the PPS/WGS relationship for dataset projects.

## 0.1.2 - 2026-06-10

- Added provenance requirements, dataset readiness levels, and validation rules.
- Expanded dataset manifest and provenance record templates.
- Added a filled provenance record example.

## 0.1.1 - 2026-06-10

- Added SFDS two-layer suite metadata to the DDS standard manifest.
- Added a DDS suite map example.
- Clarified README, adoption, and validation language for suite conformance versus dataset readiness.

## 0.1.0 - 2026-06-10

- Created initial DDS documentation suite.
